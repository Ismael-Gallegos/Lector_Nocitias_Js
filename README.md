# Lector de Noticias con Fetch, JSON y AJAX

Este proyecto forma parte del **Reto 5** del módulo *Programación Web del Lado del Cliente* de UVEG.  
El objetivo es desarrollar una aplicación web capaz de **cargar y mostrar noticias en tiempo real**, utilizando:

- **Fetch API** para realizar solicitudes HTTP.
- **AJAX** para refrescar la información sin recargar la página.
- **JSON** como formato de intercambio de datos.
- **JavaScript** para procesar y renderizar las noticias.
- **HTML y CSS** para estructurar y estilizar la interfaz.

---

## 📌 Funcionalidades principales

- Obtención de noticias desde **NewsAPI**.
- Filtrado por **país** y **categoría** (ej. tecnología).
- Procesamiento de la respuesta en formato JSON.
- Presentación de noticias en tarjetas con:
  - Título  
  - Descripción  
  - Fecha  
  - Enlace a la noticia completa  
- Botón para **refrescar noticias** sin recargar la página.
- Manejo de errores:
  - API no disponible  
  - Respuesta vacía  
  - Problemas de red
